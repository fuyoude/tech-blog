# ISIS 链路状态数据库

IS-IS 支持两级区域的网络分层体系结构，两级区域分别是 L1 区域和 L2 区域，L1 区域只支持区域内的路由，而 L2 区域支持区域间的路由。每个区域内的路由器都会在区域内泛洪自己的 LSP，也就是说，L1 的 LSP 在 L1 区域内泛洪，L2 的 LSP 会在 L2 区域内泛洪，最终使得区域内的路由器的链路状态数据库都是同步的。在 L1 区域中的路由器只需要构建和维护一张 L1 的数据库，L2 区域内的路由器也只有一张 L2 的数据库，但是 L1/2 路由器需要两张数据库（L1 和 L2），图 4-17 显示了一个典型的 IS-IS 网络结构及其链路状态数据库的情况。
